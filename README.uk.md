# cs2-res-switcher

[English](README.md) | **Українська**

Легка фонова утиліта для Windows. Коли запускається **CS2** (`cs2.exe`), вона перемикає **тільки основний монітор** на ігрову роздільність (за замовчуванням 1280×960). Коли гра закривається, робочий стіл повертається точно таким, яким був. Другого монітора програма не торкається.

## Встановлення

1. Відкрийте **[Releases](../../releases/latest)** і скачайте `cs2-res-switcher-setup-X.Y.Z.exe`.
2. Запустіть файл. Права адміністратора не потрібні.
   - **Якщо браузер блокує завантаження** (Edge пише «зазвичай не завантажується»), натисніть `Ctrl+J`, потім **«…» → Зберегти → Показати більше → Усе одно зберегти**.
   - **Якщо Windows показує синє вікно SmartScreen** («Windows захистила ваш комп'ютер»), натисніть **«Докладніше» → «Виконати все одно»**. Воно з'являється, бо програма нова і не має платного цифрового підпису.
3. Виберіть мову інсталятора. Програма буде тією самою мовою (українською або англійською).
4. За бажанням поставте галочку **«Запускати разом з Windows»**.
5. Готово: у треї біля годинника з'явиться маленька іконка монітора.

Видалення: **Параметри → Програми → cs2-res-switcher → Видалити**.

## Як користуватися

| Колір іконки в треї | Що означає |
|---|---|
| сірий | очікування гри |
| зелений | увімкнено ігрову роздільність |
| жовтий | пауза |

Правий клік по іконці відкриває меню:

- **Статус**: показує, що програма робить зараз.
- **Пауза / Відновити**: тимчасово вимикає автоматичне перемикання.
- **Перемкнути вручну**: перемикає без гри, зручно для швидкої перевірки. Повторний клік повертає робочий стіл.
- **Мова / Language**: виберіть **Українська** або **English**. Вибір зберігається.
- **Вихід**: перед закриттям завжди повертає роздільність робочого столу.

## Налаштування (`config.toml`)

Файл створюється при першому запуску поруч із програмою. Відкрити його можна через **Пуск → cs2-res-switcher → config.toml**. Після змін вийдіть із програми через трей і запустіть її знову.

```toml
process_name = "cs2.exe"   # яку гру відстежувати
width = 1280
height = 960
refresh_rate = 0           # 0 = максимальна частота монітора, або точне значення, напр. 240
poll_interval_ms = 1000    # як часто перевіряти, чи запущена гра
scaling = "stretch"        # "stretch" = розтягнуте 4:3, "center" = з чорними смугами, "driver" = не чіпати
language = "auto"          # "auto" = мова Windows, "uk" = українська, "en" = англійська
```

Якщо роздільність не перемикається, відкрийте `cs2-res-switcher.log` поруч із програмою. Там написано, які частоти монітор підтримує для цієї роздільності.

## Як зробити перемикання швидшим

- **NVIDIA:** Панель керування NVIDIA → «Регулювання розміру та положення робочого столу» → режим «На весь екран», «Виконати масштабування на: **ГП**», галочка «Заміщення режиму масштабування, заданого іграми та програмами». Тоді монітор зберігає свій рідний сигнал, і чорний екран майже зникає.
- **AMD:** Adrenalin → Дисплей → «GPU Scaling: увімкнено», «Scaling Mode: Full panel».
- **Windows 11:** Параметри → Система → Дисплей → Графіка → «Оптимізація для віконних ігор» → увімкнути.

## Як це працює

- Основний монітор визначається через `EnumDisplayDevicesW` (`DISPLAY_DEVICE_PRIMARY_DEVICE`).
- Поточний режим зберігається через `EnumDisplaySettingsW(ENUM_CURRENT_SETTINGS)` і відновлюється точно таким самим.
- Перемикання йде через `ChangeDisplaySettingsExW` з прапором `0`. Зміна тимчасова і ніколи не записується в реєстр, тож навіть після аварійного завершення перезавантаження повертає звичайну роздільність.
- Процес гри перевіряється через `sysinfo` раз на секунду, тому навантаження на процесор практично нульове.
- Програма не збирає жодних даних і не підключається до мережі.

## Збірка з коду

Потрібен [Rust](https://rustup.rs). Для інсталятора також потрібен [Inno Setup 6](https://jrsoftware.org/isinfo.php).

```bash
cargo build --release
```

```bash
powershell -ExecutionPolicy Bypass -File build-installer.ps1
```

Інсталятор з'явиться в папці `dist`.
